# Files reused from ReelMimic

From [edenfunf/reelmimic](https://github.com/edenfunf/reelmimic) (MIT, see `LICENSE-reelmimic.txt`), commit 0202bd7:

- `scripts/`: `.claude/skills/video-clone/scripts/` (analysis, comparison, lyric timing, licence-safe asset search, timeline). Unchanged.
- `styles/`: `.claude/skills/video-clone/styles/` (the style registry: one Markdown file per style). Unchanged; add your own
  style by copying `_TEMPLATE.md`.
- `fonts/`: caption fonts from `.claude/skills/embedded-captions` (Google Fonts, SIL Open Font License 1.1).

The full upstream repository is also kept in `apps/reelmimic` for reference. The studio uses these copies, so it runs
even if that folder is missing.
