# Blender assets (Mixamo etc.)

- `characters/` - rigged characters, FBX from mixamo.com (T-pose, with skin). Name them
  `man.fbx`, `woman.fbx`, `giant.fbx`, `kid.fbx` ... to replace the built-in mannequin.
- `animations/` - Mixamo animations (FBX, **Without Skin**, "In Place"). Name them by
  action: `punch.fbx`, `walk.fbx`, `run.fbx`, `jump.fbx`, `idle.fbx`, `fall.fbx` ...
- `props/` - any .glb / .fbx / .obj model; the file name is the prop name.

Full guide: ../blender_service/README.md
