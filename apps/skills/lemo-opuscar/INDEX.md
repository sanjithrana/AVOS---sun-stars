# Lemo-Opuscar style library — the index

66 film styles, every one rendered in code with no video model. Each folder holds that style's `STYLE.md` (the style prompt) and `style.json` (its metadata).

Generated from the repository's own `style.json` files. The demo films, posters and per-style renderer code are **not** vendored here — see README-AVOS.md.
