# Continuity

After each approved part, write down what the next writers must know.

- **summary**: 1-3 sentences: who did what, what changed, where it left off (English).
- **facts**: only NEW things that must stay true later: a broken object, a secret someone now knows, a new neighbour,
  an injury, a promise. Short, concrete, one per line. Not plot summaries.
