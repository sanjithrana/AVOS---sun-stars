# Explainer Studio workflow
Choose "Ask me at each step" or "Fully automatic".
| Stage | Makes | Gate |
|---|---|---|
| Plan | research, script, JSON plan (up to 16 shots, 14 film fields) | approve/change script |
| Design | character sheets, props, empty set, key poster | approve/redraw |
| Board | first frame per shot, quality-checked, contact sheet | approve/redraw |
| Shoot | voice, dialog, then lip-sync / Blender / AI video / still+camera move | none |
| Finish | fit clips, mix, captions: final.mp4, final.srt | none |
Shot router: forced choice, lip-sync for speakers, Blender for physics, AI video, still with camera move.
11 skills (switchable on the Skills page); approvals and redraws teach the prompt library.
